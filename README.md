# Clipshelf

A free, open-source clipboard manager for macOS that feels like part of the system.

Clipshelf keeps everything you copy on a shelf at the bottom of the screen: text, links, images, files and colors. Search it, organize it into boards and paste anything back with a keystroke.

> **Status:** early development. There is no release yet.

## Planned features

- Unlimited clipboard history with configurable retention
- A shelf of cards with previews for each content type
- Boards for keeping snippets you reuse
- Search with filters by type and source app
- Paste directly into the frontmost app, or as plain text
- Quick paste with numbered shortcuts
- Sequential pasting of several items
- Editing items before pasting
- Privacy controls: ignored apps, password managers and concealed content are skipped
- Everything stays on your Mac. No account, no telemetry, no sync for now.

## Requirements

macOS 26 or later.
